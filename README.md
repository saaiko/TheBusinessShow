# غرفة القرار — The Decision Room
### عرض تقديمي للبرنامج الأسبوعي الرئيسي لـ CNN Business Arabic

عرض تفاعلي بصيغة HTML (عربي، اتجاه RTL، بأسلوب رقمي أولًا) يقدّم مفهوم البرنامج،
بنيته، الحلقة التجريبية (القطاع العقاري)، منظومة المحتوى، نموذج الإنتاج، الموسم الأول،
والهوية البصرية للديكور والرسومات.

## كيفية العرض
افتح `index.html` في أي متصفّح حديث (يفضّل بملء الشاشة).

- **التنقّل:** مرِّر للأسفل، أو استخدم مفاتيح الأسهم / Space / Page Up-Down، أو النقاط الجانبية.
- **للتصدير PDF:** من المتصفّح → طباعة → حفظ كـ PDF (أفقي، A4/16:9).

## بنية العرض (19 شريحة)
1. الغلاف · 2. الفكرة · 3. لماذا مايا · 4. البنية (٤ حركات) · 5. الكرسي المقابل ·
6. لحظة مايا · 7–8. الحلقة التجريبية (العقارات) + Runsheet · 9. اقتصاد الناس ·
10. منظومة المحتوى · 11. الإنتاج + القواعد التحريرية · 12. الموسم الأول (12 حلقة) ·
13. الديكور · 14. لوحة الخامات · 15. رسومات الشاشة · 16. الإطار الرقمي/العمودي ·
17. لماذا سينجح · 18. الخطوات التالية · 19. الختام.

## تعديلات مقترحة لأسلوب «رقمي» لا «تلفزيوني»
- **زمن الحلقة:** ضبط الحلقة الكاملة عند **~22–24 دقيقة** (بدل 26–28) لملاءمة الاحتفاظ الرقمي.
- **التصوير:** إضاءة وكادر يخدمان الأفقي والعمودي معًا (مناطق آمنة لقصّ 9:16 من التصوير، لا بترًا لاحقًا).
- **الرسومات:** ترجمة وكتابات متحرّكة (kinetic captions) بالعربية مدمجة من التصوير — أقوى إشارة على الطابع الرقمي.
- **الديكور:** أبيض دافئ + عنصر طبيعي واحد (سنديان فاتح/حجر) حتى لا يبدو الاستوديو فارغًا على الكاميرا،
  مع لمسة حمراء مقتصَدة تربطه بهوية CNNBA.

## نسخة PowerPoint قابلة للتعديل
ملف `The_Business_Show.pptx` نسخة **قابلة للتحرير بالكامل** بنفس نظام التصميم (الألوان،
الخط العربي RTL، اللمسة الحمراء، البطاقات والجداول، الشعار) مع **انتقالات حركية بين الشرائح
(Morph / Fade)** لأقرب إحساس بالحركة الممكن في PowerPoint.

- **الصور:** يحاول مولّد الملف تنزيل الصور وتضمينها تلقائيًا.
  - إذا شغّلته على جهاز متصل بالإنترنت → تُضمَّن **الصور الحقيقية** تلقائيًا.
  - في بيئة مقيّدة الشبكة → تُرسم إطارات صور احتياطية، ويُكتب رابط كل صورة في **ملاحظات الشريحة**.
- **لتوليد النسخة النهائية بالصور مضمّنة على جهازك:**
  ```bash
  pip install python-pptx pillow
  python build_pptx.py        # ينتج The_Business_Show.pptx مع الصور
  ```
- **الخطوط:** للحصول على المظهر الدقيق، ثبّت خطي **Cairo** و **Tajawal** المجانيين (Google Fonts).
  في غيابهما يستبدلهما PowerPoint تلقائيًا دون كسر التصميم.
- **الحركة:** الانتقالات مضمّنة؛ في PowerPoint فعّل «تشغيل العرض» لرؤية تأثير Morph بين الشرائح.

> النسخة الأساسية والأعلى دقة بصريًا تبقى `index.html` (بحركة كاملة)؛ وملف PowerPoint للفرق التي تحتاج تحرير الشرائح.

## الأصول البصرية (Concept Visuals)
الصور المستخدمة في العرض هي **تصاميم مبدئية (concept renders)** مُولّدة للعرض التقديمي،
ومستضافة حاليًا عبر روابط خارجية. تظهر مباشرة عند فتح العرض في المتصفّح.

> **ملاحظة للأرشفة طويلة المدى:** ينبغي تنزيل الصور وتخزينها محليًا داخل `assets/img/`
> وتحديث مسارات `src` في `index.html` قبل الاعتماد الدائم، لتفادي انقطاع الروابط الخارجية.

قائمة الأصول موجودة في `assets/img/MANIFEST.md`.
